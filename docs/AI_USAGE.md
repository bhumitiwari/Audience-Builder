# AI Usage

The design ideas, architecture, and implementation logic were conceived and driven by me. I used AI tools (ChatGPT and GitHub Copilot) primarily as an assistant for drafting markdown documentation, code autocompletion, and quick syntax lookups.

### How I used AI:
- **Documentation Formatting**: Used AI to help structure and draft the markdown files (such as `README.md` and design notes) based on my architectural outline and requirements.
- **Autocomplete & Boilerplate**: Used Copilot for routine typing, enumerating repetitive mock event lists, and standard TypeScript interfaces.
- **Syntax Lookups**: Checked syntax and method references for Node's built-in `node:sqlite` API and Tailwind utility classes.
- **Edge Case Double-Checking**: Sanity-checked boundary date arithmetic (e.g. verifying that events after `asOf` are cleanly excluded).

The overall system design, database schemas, evaluator logic, API routing, React state handling, and automated tests were architected, tested, and verified by me.
